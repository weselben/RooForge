# ste100

STE100 applies ASD-STE100 Simplified Technical English to all human-facing text the agent produces: PR bodies, commit messages, issue comments, and documentation. It enforces short sentences, approved vocabulary, imperative mood, active voice, and one-meaning-per-word discipline. Chat replies are not in scope; the skill governs artifacts only.

## When to load

- Writing or revising a PR description (forge step 5 loads it explicitly).
- Composing long-form documentation, guides, or reports.
- Drafting commit messages, issue comments, or any text another human will read.
- A sentence resists the core rules and needs the extended digest.

## How it works

1. **Apply core rules** (`SKILL.md:16-34`). One topic per sentence. Max 20 words for instructions, 25 for descriptions. Max 6 sentences per paragraph. Imperative mood, active voice. One word per meaning, everywhere.
2. **Use approved vocabulary.** Prefer short approved words ("use" not "utilize", "show" not "demonstrate"). No contractions, no idioms, no phrasal ambiguity.
3. **Tense and mood.** Present tense for facts, past for completed actions, future only for truly later events. "must" = obligation, "can" = capability, "should" = recommendation.
4. **Load extended rules** (`RULES.md`) when writing long-form text or when a sentence resists the core rules. The digest adds:
   - Length limits by text type (instructions 20 words, descriptions 25 words, warnings 25 words).
   - Approved function words: "and"/"or" (never both in one sentence), "because" (not "since"/"due to"), "so that" (not "in order to").
   - Punctuation discipline: semicolons banned, em-dashes banned, hyphens for compound modifiers only.
   - Warning/note formatting: danger first then avoidance action; "NOTE:" prefix for skippable info.
5. **Run the verification checklist** (`RULES.md:46-54`) on any long human-facing text before delivery: every sentence under word limit, every thing named consistently, imperative mood, no "-ing" verb substitutes, correct must/can/should usage.
6. **Respect boundaries** (`SKILL.md:47-49`). STE100 shapes prose; it does not strip required format (commit type prefixes, PR headings, AI-attribution trailers) or censor facts. If the user requests a different tone, the user wins for that text.

## Files in this skill

- `skills/ste100/SKILL.md` — Core rules, examples, and scope boundaries (49 lines).
- `skills/ste100/RULES.md` — Extended rule digest: length limits, approved-word discipline, punctuation, warnings, and verification checklist (54 lines).
